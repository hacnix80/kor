# 난지캠핑장 빈자리 알림 (일반캠핑존 B·C·D형)

집 PC의 Chrome에서 돌아가는 사용자 스크립트입니다. 지정한 날짜의 빈자리를 정해진 간격마다 확인하고, 자리가 생기면 텔레그램으로 알려 줍니다. **예약은 하지 않습니다.** 알림을 받으면 직접 들어가서 예약하세요.

## 동작 방식

- 서울시 공공서비스예약 사이트는 자동 프로그램의 직접 조회를 막아 둡니다. 그래서 이 스크립트는 사이트를 우회하지 않습니다. **평소 쓰는 Chrome에서 사이트 탭을 열어 두면**, 그 탭 안에서 상세 페이지를 보이지 않게 다시 열고 사이트가 그린 달력을 읽습니다. 사람이 새로고침해서 확인하는 것과 같은 방식입니다.
- 예약 서비스는 월마다 따로 올라옵니다(예: "12월 일반캠핑존 B형"). 스크립트가 목록에서 해당 월·구역을 자동으로 찾습니다. 아직 오픈 전인 달은 "오픈 전"으로 표시하고, 올라오면 바로 검색을 시작합니다.
- 같은 자리에 대한 알림은 한 번만 보냅니다. 마감됐다가 다시 자리가 나면 또 보냅니다.
- PC와 Chrome이 켜져 있고 해당 탭이 열려 있어야 동작합니다. 절전 모드에 들어가면 멈춥니다.

## 설치 (처음 한 번만)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather**를 찾아 `/newbot`을 보내고 이름을 정합니다. 그러면 **봇 토큰**을 줍니다(`123456:ABC...` 형식).
2. 만든 봇과 대화를 열어 아무 메시지나 한 번 보냅니다.
3. 브라우저 주소창에 `https://api.telegram.org/bot<봇토큰>/getUpdates`를 엽니다. 결과에서 `"chat":{"id":숫자` 부분의 숫자가 **chat_id**입니다.

### 2. Tampermonkey 설치
1. Chrome 웹스토어에서 **Tampermonkey** 확장 프로그램을 설치합니다.
2. Chrome 확장 프로그램 관리(`chrome://extensions`)에서 Tampermonkey의 **세부정보**를 엽니다. **"사용자 스크립트 허용"**을 켭니다. 버전에 따라서는 오른쪽 위 **개발자 모드**를 켜야 합니다.
3. Tampermonkey 아이콘에서 **새 스크립트 만들기**를 누릅니다. 기본 내용을 모두 지우고 `nanji-watch.user.js` 내용을 붙여 넣은 뒤 저장합니다(Ctrl+S).

## 사용법

1. Chrome에서 `https://yeyak.seoul.go.kr/web/main.do` 를 엽니다.
2. 오른쪽 아래에 **⛺ 난지캠핑장 빈자리 알림** 창이 뜹니다. 아래 항목을 입력합니다.
   - **날짜**: `2026-12-19, 2026-12-20` 처럼 쉼표로 구분합니다. 1박 날짜, 즉 입실일 기준입니다.
   - **구역**: `B,C,D` (원하는 것만 적어도 됩니다)
   - **검색 간격**: 분 단위입니다. 최소 1분, 권장 3~5분입니다.
   - **봇 토큰 / chat_id**
3. **알림 테스트**를 눌러 텔레그램이 오는지 확인합니다.
4. **저장 후 시작**을 누릅니다. 이 탭은 닫지 말고 그대로 두세요. 다른 탭에서는 평소처럼 브라우저를 써도 됩니다.

설정은 저장됩니다. Chrome을 다시 켜서 같은 주소를 열면 자동으로 다시 시작합니다.

## 참고

- 사이트가 접근을 막으면(차단 안내 페이지로 넘어가면) 스크립트가 스스로 멈추고 텔레그램으로 알려 줍니다. 그때는 간격을 늘려서 다시 시작하세요.
- 사이트 구조가 바뀌면 동작하지 않을 수 있습니다. 창의 로그에 "달력 로딩 시간 초과"가 계속 뜨면 구조가 바뀐 것입니다.
- 매월 15일 14시에 다음 달 예약이 열리고, 결제 대기(2시간) 후 취소된 자리가 다시 나오는 경우가 많습니다.
